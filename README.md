Order Handling Time Service

Backend application in Python (Django) for managing order handling time in alignment with user-defined shipment dates.

The service allows the user to define the desired shipment date, and dynamically calculates the required handling time (in days) to be sent to external systems such as Allegro.

Its main goal is to ensure that the declared handling time matches the actual planned shipment date.

This project is intended as a base for further development, including:
- REST API
- business logic for order processing
- integration with external systems (e.g. Allegro)

Technologies

- Python 3
- Django
- PostgreSQL

Project Status

The project is in an early stage of development.
